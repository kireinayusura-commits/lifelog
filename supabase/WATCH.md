# Apple Watch から使う

Watch には Kirimori 自体を入れられません（ホーム画面に追加する形のアプリなので、
watchOS では動きません）。代わりに **「ショートカット」アプリから
サーバーへ直接1回だけ通信する** 形にします。

サーバーに記録が入れば、あとは今までどおりの同期が働いて、
**iPhone にもパソコンにも数秒で届きます。**

できること：

| ショートカット | 押すと |
| --- | --- |
| **計測** | 計測中なら止めて記録に残す／止まっていれば始める（押すたびに入れ替わる） |
| **支出** | 金額を入れて、タグを選んで記録する |
| **状態** | いま計測中かどうかを見るだけ（設定の確認用） |

所要 20 分ほど。**1 と 2 は iPhone で行います。**

---

## 1. サーバー側の準備（1回だけ）

1. Supabase のダッシュボード → **SQL Editor** → **New query**
2. `supabase/watch.sql` の**全文**を貼って **Run**
3. `Success. No rows returned` と出れば完了

何度実行しても安全です。先に `supabase/schema.sql` を実行しておいてください。

---

## 2. 合鍵を作る（1回だけ）

ショートカットにメールアドレスとパスワードを書かせたくないので、
**Watch 専用の「合鍵」を1本だけ**持たせます。

1. iPhone で Kirimori を開き、**設定 → Apple Watch から操作**
2. **「合鍵を作る」** を押す
3. **「つながるか試す」** を押して、`計測していません（今日 …）` のように返れば成功

> ここで「サーバー側の準備がまだです」と出たら、手順 1 が済んでいません。

このあとの手順で使う値は、同じ画面の **「貼り付ける値を見る」** に全部あります。
それぞれ右の「コピー」を押してから、ショートカットに貼ってください。

---

## 3. ショートカットを作る

### 3-1. 「状態」— まずこれで通信を確かめる

一番単純なので、最初にこれを作って**通信が通ることだけを確かめます。**

1. **ショートカット** アプリ → 右上の **＋**
2. **「アクションを追加」** → 検索欄に `URL` → **「URLの内容を取得」**
3. URL 欄に、アプリの **URL（状態の確認）** を貼る
4. アクションの中の **「詳細を表示」** を開く
5. **方法** を **POST** にする
6. **ヘッダ** → 「新規ヘッダを追加」を2回押して、次の2つを入れる

   | キー | 値 |
   | --- | --- |
   | `apikey` | アプリの **ヘッダ apikey** の値 |
   | `Authorization` | `Bearer ` のあとに同じ値（`Bearer` と値の間に**半角スペース1つ**） |

7. **本文を要求** を **JSON** にする → 「新規フィールドを追加」→ **テキスト**

   | キー | 値 |
   | --- | --- |
   | `k` | アプリの **合鍵** |

8. 下に **「結果を表示」** のアクションを足す
9. 上の名前を **「状態」** にして完了

▶ を押して `計測していません（今日 0秒）` のように出れば、**通信は通っています。**

<details>
<summary>引用符（" "）が前後に付くのが気になるとき</summary>

ヘッダをもう1つ足してください。

| キー | 値 |
| --- | --- |
| `Accept` | `text/plain` |

これで文字だけが返ります。もしエラーになる場合は、このヘッダを消してください。
引用符が付くだけで、動作は変わりません。
</details>

### 3-2. 「計測」— 開始と停止

**3-1 をまるごと複製して、URL だけ差し替える**のが早いです。

1. 「状態」を長押し → **複製**
2. URL を **URL（タイマー）** に差し替える
3. 名前を **「計測」** にする

これで完成です。押すたびに、

- 止まっているとき → `英語 で開始しました`
- 計測中のとき → `英語 1時間05分 を記録しました`

と返ります。

> **タグは直前の記録から引き継ぎます。**
> いつも同じことを計るなら、これで毎回合います。
> 特定のタグで始めたいときは、本文に `tag` というテキストのフィールドを足し、
> 値にタグ名（例：`英語`）をそのまま入れてください。

### 3-3. 「支出」— 金額とタグ

アクションを **5つ** 並べます。

| # | アクション | 設定 |
| --- | --- | --- |
| 1 | **入力を要求** | 入力タイプ **数字**、質問「いくら？」 |
| 2 | **URLの内容を取得** | URL＝**URL（タグ一覧）**／POST／ヘッダは 3-1 と同じ<br>本文 JSON：`k`＝合鍵（テキスト）、`purpose`＝`money`（テキスト） |
| 3 | **リストから選択** | 一覧＝手順2の「URLの内容」 |
| 4 | **URLの内容を取得** | URL＝**URL（支出）**／POST／ヘッダは 3-1 と同じ<br>本文 JSON：`k`＝合鍵（テキスト）、`amount`＝手順1の「指定入力」（**数字**）、`tag`＝手順3の「選択された項目」（テキスト） |
| 5 | **結果を表示** | — |

名前を **「支出」** にして完了。

押すと「いくら？」→ タグの一覧 → `食費 680円 を記録しました` と進みます。
**タグの一覧はアプリのタグをそのまま出す**ので、アプリでタグを増やせば
ショートカットを直さなくても増えます。

> **タグを選ぶのが面倒なとき**は、手順 2・3 を消して、
> 手順 4 の `tag` フィールドも消してください。金額だけの1ステップになります。
> 名前は「Watchから記録」で入るので、あとから iPhone で直せます。

---

## 4. Apple Watch に出す

1. ショートカットの右上の **…**（または長押し → 詳細）から、**ⓘ** のタブを開く
2. **「Apple Watchに表示」** をオンにする
3. 3つとも同じようにオンにする

Watch 側の **ショートカット** アプリを開くと一覧に出ます。

さらに手が届きやすくするなら：

- **文字盤に置く**：文字盤を長押し → 編集 → コンプリケーションに「ショートカット」→ 目的のものを選ぶ
- **スマートスタック**：下から上にスワイプして出てくる並びにも追加できます
- **アクションボタン**（Ultra）：設定 → アクションボタン → ショートカット

> Watch 単体（LTE・Wi-Fi）でも、iPhone が近くにあるときでも動きます。
> どちらも無い場所では失敗します（記録が壊れることはありません。押し直してください）。

## 5. うまくいかないとき

**「サーバー側の準備がまだです」**
手順 1 の `watch.sql` が未実行です。実行して 1 分ほど待ってから試してください。

**`合鍵が違います`**
ショートカットに貼った `k` の値が、いまの合鍵と違います。
アプリの設定画面から合鍵をコピーし直して貼り替えてください。
（「作り直す」を押すと、前の合鍵はその場で使えなくなります）

**`permission denied` / 401**
ヘッダの `apikey` か `Authorization` が入っていません。
`Authorization` は `Bearer ` を前に付けた形です（半角スペースを1つ）。

**押しても iPhone に出てこない**
iPhone の Kirimori を開き直してください。開いた瞬間に取りに行きます。
それでも出ないときは、設定画面の「すぐ届く状態です」が緑になっているか確認してください。

**Watch に一覧が出ない**
手順 4 の「Apple Watchに表示」がオフのままです。
オンにしたあと、Watch 側のショートカットアプリを一度閉じて開き直してください。

---

## 6. 安全について

合鍵を持っている人は、**あなたの記録を足したり、計測を止めたりできます。**
ただし、

- **記録を読むことはできません**（合鍵でできるのは、決まった4つの操作だけです）
- 他人の記録には一切手が届きません
- 合鍵は 32 文字（約160ビット）で、総当たりで当てられる長さではありません
- 人に見られたかもしれないときは、アプリの **「作り直す」** でその場で失効します

合鍵は**ショートカットの中だけ**に置いてください。
GitHub に上げるファイルや、人に見せるメモには書かないこと。
