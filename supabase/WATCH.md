# Apple Watch から使う

Watch には Kirimori 自体を入れられません（ホーム画面に追加する形のアプリなので、
watchOS では動きません）。代わりに **「ショートカット」アプリから
サーバーへ直接1回だけ通信する** 形にします。

サーバーに記録が入れば、あとは今までどおりの同期が働いて、
**iPhone にもパソコンにも数秒で届きます。**

できること：

| ショートカット | 押すと |
| --- | --- |
| **計測** | 計測中なら止めて記録に残す／止まっていれば始める（押すたびに入れ替わる） |
| **支出** | タグを選んで金額を入れて記録する |
| **取消** | Watch から入れた直前の支出を取り消す |
| **状態** | いま計測中かどうかを見るだけ（設定の確認用） |

所要 20 分ほど。**1 と 2 は iPhone で行います。**

---

## 1. サーバー側の準備（1回だけ）

1. Supabase のダッシュボード → **SQL Editor** → **New query**
2. `supabase/watch.sql` の**全文**を貼って **Run**
3. `Success. No rows returned` と出れば完了

何度実行しても安全です。先に `supabase/schema.sql` を実行しておいてください。

---

## 2. 合鍵を作る（1回だけ）

ショートカットにメールアドレスとパスワードを書かせたくないので、
**Watch 専用の「合鍵」を1本だけ**持たせます。

1. iPhone で Kirimori を開き、**設定 → Apple Watch から操作**
2. **「合鍵を作る」** を押す
3. **「つながるか試す」** を押して、`計測していません（今日 …）` のように返れば成功

> ここで「サーバー側の準備がまだです」と出たら、手順 1 が済んでいません。

このあとの手順で使う値は、同じ画面の **「貼り付ける値を見る」** に全部あります。
それぞれ右の「コピー」を押してから、ショートカットに貼ってください。

---

**合鍵だけがあなた固有**で、残りは全部この通りです。
アプリの設定画面にも同じ値が「コピー」ボタン付きで出ています。

### 本文（「本文を要求」を **JSON** にして、フィールドを足す）

| URL | キー | 型 | 値 |
| --- | --- | --- | --- |
| watch_status | `k` | テキスト | 合鍵 |
| watch_toggle | `k` | テキスト | 合鍵 |
| watch_tags | `k` | テキスト | 合鍵 |
| | `purpose` | テキスト | `money` |
| watch_expense | `k` | テキスト | 合鍵 |
| | `amount` | **テキスト** | 入力した金額 |
| | `tag` | テキスト | 選んだタグ名 |
| watch_undo | `k` | テキスト | 合鍵 |

> **決まった名前のフィールドしか受け付けません。**
> 余計なものを足すと「関数が見つからない」と返ってきます。
>

> 数字のフィールドはキーボードがテンキーになり、変数を入れる帯が出ないことがあります。
> テキストなら普通のキーボードになって、変数をそのまま入れられます。
> `１２３０`・`¥1,480`・`980円` のような書き方もサーバー側で読み取ります。

## 4. ショートカットを作る

### 4-1. 「状態」— まずこれで通信を確かめる

一番単純なので、最初にこれを作って**通信が通ることだけを確かめます。**

1. **ショートカット** アプリ → 右上の **＋**
2. **「アクションを追加」** → 検索欄に `URL` → **「URLの内容を取得」**
3. URL 欄に、アプリの **URL（状態の確認）** を貼る
4. アクションの中の **「詳細を表示」** を開く
5. **方法** を **POST** にする
6. **ヘッダ** → 「新規ヘッダを追加」を2回押して、次の2つを入れる

   | キー | 値 |
   | --- | --- |
   | `apikey` | アプリの **ヘッダ apikey** の値 |
   | `Authorization` | `Bearer ` のあとに同じ値（`Bearer` と値の間に**半角スペース1つ**） |

7. **本文を要求** を **JSON** にする → 「新規フィールドを追加」→ **テキスト**

   | キー | 値 |
   | --- | --- |
   | `k` | アプリの **合鍵** |

8. 下に **「結果を表示」** のアクションを足す
9. 上の名前を **「状態」** にして完了

▶ を押して `計測していません（今日 0秒）` のように出れば、**通信は通っています。**

<details>
<summary>引用符（" "）が前後に付くのが気になるとき</summary>

ヘッダをもう1つ足してください。

| キー | 値 |
| --- | --- |
| `Accept` | `text/plain` |

これで文字だけが返ります。もしエラーになる場合は、このヘッダを消してください。
引用符が付くだけで、動作は変わりません。
</details>

### 4-2. 「計測」— 開始と停止

**4-1 をまるごと複製して、URL だけ差し替える**のが早いです。

1. 「状態」を長押し → **複製**
2. URL を **URL（タイマー）** に差し替える
3. 名前を **「計測」** にする

これで完成です。押すたびに、

- 止まっているとき → `英語 で開始しました`
- 計測中のとき → `英語 1時間05分 を記録しました`

と返ります。

> **タグは直前の記録から引き継ぎます。**
> いつも同じことを計るなら、これで毎回合います。
> 特定のタグで始めたいときは、本文に `tag` というテキストのフィールドを足し、
> 値にタグ名（例：`英語`）をそのまま入れてください。

### 4-3. 「支出」— 金額とタグ

> ### ⚠ Watch では「リストから選択」に頼らないこと
>
> **サーバーから取ったタグ一覧を「リストから選択」に渡す作りは、iPhone では動きますが
> Apple Watch では動きません。** watchOS は受け取った JSON の配列を
> リストとして解釈せず、ただの文字列として渡してしまうため、
> **一覧が文字で表示されるだけで選べず、そこで終わります**（記録もされません）。
>
> Watch で使うなら、下の **タグごとに1つずつ作る形** が確実です。
> 使うアクションが「入力を要求」と「URLの内容を取得」だけになり、
> どちらも Watch で動くことが確認済みです。

**通信は1回だけにします。** タグの一覧をサーバーから取ってくる作り方もできますが、
その場合「URLの内容」という名前の変数が1つのショートカットに2つでき、
**どちらを指しているのか区別が付かなくなります。**
金額が変な値になる・タグが付かない・最後に出る結果がタグ一覧になる、
という不具合はここから起きます。

タグは手で並べてください。増えるのは年に数回のはずで、
そのときだけ書き足すほうが、毎回2回通信するより速くて確実です。

**タグごとに1つずつ作ります。** 「食費」「日用品」のように、
よく使うタグの数だけショートカットを用意する形です。
Watch では手首を上げて1タップで目的のものを押せるので、
一覧から選ぶより速く、仕組みも単純で壊れません。

| # | アクション | 設定 |
| --- | --- | --- |
| 1 | **入力を要求** | 入力タイプ **数字**、質問「いくら？」 |
| 2 | **URLの内容を取得** | URL＝`.../rpc/watch_expense`／POST／ヘッダは 4-1 と同じ |
| 3 | **結果を表示** | — |

手順 3 の **本文を要求（JSON）** は3つ：

| キー | 型 | 値 |
| --- | --- | --- |
| `k` | テキスト | 合鍵 |
| `amount` | **テキスト** | 手順2の **指定入力** |
| `tag` | テキスト | 手順1の **選択された項目** |

名前を**タグ名そのもの**（「食費」など）にして完了。
押すと「いくら？」だけ聞かれ、`食費 680円 を記録しました` と返ります。

> **値の欄には、青い変数の塊が1つだけ入っている状態が正解です。**
> 手で打った文字や、同じ変数がもう1つ並んでいると、それがつながって送られます
> （680 と入れたのに **680680** になる、タグが **食費食費** になって見つからない）。
> 欄をタップしたら削除キーで**空になるまで全部消し**、キーボードの上の帯から
> 「指定入力」「選択された項目」を**1回だけ**タップしてください。
> 帯が出ないときは、欄を長押し →「変数を選択」でも入れられます。

#### 入れたあとに間違いに気づいたら

`.../rpc/watch_undo` を呼ぶショートカット（4-1 の複製で、URL を差し替えるだけ）を
**「取消」** という名前で作っておくと、**Watch から直前の1件を取り消せます。**
`食費 680円 の記録を取り消しました` と返ります。二度押しても、それより前の記録は消えません。

#### 二度押しについて

同じ金額・同じタグを **10秒以内** にもう一度送ると、サーバーが同じ操作とみなして
`登録済みです（二重登録を防ぎました）` と返します。記録は1件のままです。
金額が1円でも違えば、別の買い物として両方入ります。

<details>
<summary>タグの一覧をサーバーから取りたい場合（上級者向け）</summary>

通信が2回になり、変数を取り違えやすくなります。
**必ず「変数を設定」を挟んで、名前で区別できるようにしてください。**

| # | アクション | 設定 |
| --- | --- | --- |
| 1 | URLの内容を取得 | `.../rpc/watch_tags`／本文 `k`＝合鍵、`purpose`＝`money` |
| 2 | **変数を設定** | 名前：`タグ一覧`、値：URLの内容 |
| 3 | リストから選択 | 入力＝`タグ一覧` |
| 4 | **変数を設定** | 名前：`タグ`、値：選択された項目 |
| 5 | 入力を要求 | 数字、「いくら？」 |
| 6 | **変数を設定** | 名前：`金額`、値：指定入力 |
| 7 | URLの内容を取得 | `.../rpc/watch_expense`／本文 `k`＝合鍵、`amount`＝`金額`（テキスト）、`tag`＝`タグ` |
| 8 | **変数を設定** | 名前：`返事`、値：URLの内容 |
| 9 | 結果を表示 | `返事` |

手順 8・9 を省くと、**結果を表示が手順1のタグ一覧を映してしまいます。**
</details>

## 5. 入れた記録の確かめ方

Watch から押したあと、iPhone の **記録タブ → 履歴** を開いて
**1件ずつの行**を見てください。

**支出タブの「今月」や合計だけを見ると、試した回数ぶんが足し算されているので、
1回ぶんの金額が大きく見えます。** 動作を確かめるときは、必ず行単位で見てください。

うまくいっていない記録は、その行を押せばその場で直せます（金額・名前・タグ）。
いらない記録は同じ画面から削除できます。

---

## 6. Apple Watch に出す

1. ショートカットの右上の **…**（または長押し → 詳細）から、**ⓘ** のタブを開く
2. **「Apple Watchに表示」** をオンにする
3. 作ったもの全部を同じようにオンにする

Watch 側の **ショートカット** アプリを開くと一覧に出ます。

さらに手が届きやすくするなら：

- **文字盤に置く**：文字盤を長押し → 編集 → コンプリケーションに「ショートカット」→ 目的のものを選ぶ
- **スマートスタック**：下から上にスワイプして出てくる並びにも追加できます
- **アクションボタン**（Ultra）：設定 → アクションボタン → ショートカット

> Watch 単体（LTE・Wi-Fi）でも、iPhone が近くにあるときでも動きます。
> どちらも無い場所では失敗します（記録が壊れることはありません。押し直してください）。

## 7. うまくいかないとき

**「サーバー側の準備がまだです」**
手順 1 の `watch.sql` が未実行です。実行して 1 分ほど待ってから試してください。

**`合鍵が違います`**
ショートカットに貼った `k` の値が、いまの合鍵と違います。
アプリの設定画面から合鍵をコピーし直して貼り替えてください。
（「作り直す」を押すと、前の合鍵はその場で使えなくなります）

**`permission denied` / 401**
ヘッダの `apikey` か `Authorization` が入っていません。
`Authorization` は `Bearer ` を前に付けた形です（半角スペースを1つ）。

**押しても iPhone に出てこない**
iPhone の Kirimori を開き直してください。開いた瞬間に取りに行きます。
それでも出ないときは、設定画面の「すぐ届く状態です」が緑になっているか確認してください。

**`金額が空のまま届きました` と出る**
`amount` の欄に変数が入っていません。
数字のフィールドだと変数を入れる帯が出ないことがあるので、
**その行を赤い − で消して、「新規フィールドを追加」→ テキスト で作り直す**のが確実です。
キーを `amount`、値に「指定入力」を1つだけ入れてください。

**`金額として読めません（届いた値：「…」）` と出る**
そこに書かれているものが、実際に送られた中身です。
変数ではなく文字が入っているか、余計な文字が混じっています。

**金額が 680680 のように2回つながる／タグが付かない**
本文の値の欄に、変数が2つ（または手で打った数字＋変数）入っています。
4-3 の囲みの手順で、欄を一度空にしてから変数を1つだけ入れ直してください。
タグ名が合わないときは、Watch に
`（タグ「食費食費」が見つからないので、タグなしにしました。使えるタグ：…）`
と、**届いた文字そのもの**が出るので、どこが違うか分かります。

**金額が思ったより大きい／最後にタグ一覧が出る**
支出のショートカットに「URLの内容を取得」が2つ入っています。
4-3 の**通信1回**の形に作り直してください。この3つは同じ原因です。

**Watch に一覧が出ない**
手順 6 の「Apple Watchに表示」がオフのままです。
オンにしたあと、Watch 側のショートカットアプリを一度閉じて開き直してください。

## 8. 安全について

合鍵を持っている人は、**あなたの記録を足したり、計測を止めたりできます。**
ただし、

- **記録を読むことはできません**（合鍵でできるのは、決まった4つの操作だけです）
- 他人の記録には一切手が届きません
- 合鍵は 32 文字（約160ビット）で、総当たりで当てられる長さではありません
- 人に見られたかもしれないときは、アプリの **「作り直す」** でその場で失効します

合鍵は**ショートカットの中だけ**に置いてください。
GitHub に上げるファイルや、人に見せるメモには書かないこと。
